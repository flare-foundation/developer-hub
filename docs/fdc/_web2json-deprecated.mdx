:::danger[Deprecated]

The `Web2Json` attestation type is deprecated and this page is no longer maintained.
To bring Web2 data onchain, build a [Flare Confidential Compute (FCC)](/fcc/overview) extension instead.
The [External API Extension](/fcc/guides/external-api-extension) guide shows an extension that fetches data from Web2 APIs over TLS and signs the result for a contract to verify.

:::
