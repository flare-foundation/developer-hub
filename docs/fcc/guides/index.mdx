These guides explain how to build a **Flare Compute Extension (FCE)** on **Coston2** with the [FCE Go scaffold example](https://github.com/flare-foundation/fce-go-scaffold) and the [`fce` command line interface](https://github.com/flare-foundation/fce-tooling).
See the [FCC overview](/fcc/overview) for more information about the protocol.

:::warning[Work in progress]
FCC is in the final stages of development.
Use **Coston2** for every guide on this page, and expect the scaffold, `fce`, and contract interfaces to change.
:::
