This page lists the current values for the most important parameters of the FAssets system on every Flare network.

App builders should start with **Flare Mainnet** and **Flare Testnet Coston2**.
Songbird is the canary network, and Coston is the protocol testnet for Songbird.
The tables below follow that order.
A setting can have a different value on each network, and governance can change it.

FXRP minting and redemption values are also collected on [FXRP Operational Parameters](/fxrp/parameters).

## Asset Manager Operational Parameters

To get the default agent settings, you need to call the `getSettings` function on the `IAssetManager` interface.
Read more about the `IAssetManager` interface [here](/fassets/reference/IAssetManager).
