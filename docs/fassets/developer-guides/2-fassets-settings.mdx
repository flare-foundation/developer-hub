Read FXRP settings from [`getSettings`](/fassets/reference/IAssetManager#getsettings) on `AssetManagerFXRP`.
Examples below use Coston2.

The TypeScript tab calls the Asset Manager with viem and reads the XRP/USD price from the FTSO.
The Solidity tab deploys a helper that reads the same asset decimals.

Resolve the Asset Manager from the registry first.
See [Resolve Asset Manager and FXRP](/fassets/developer-guides/fassets-asset-manager-address-contracts-registry).

## TypeScript

This script connects to [Coston2](/network/overview) and:

- Reads [FAssets settings](/fassets/operational-parameters), including FXRP asset decimals.
- Reads the XRP/USD price from the [FTSO](/ftso/overview).

### Prerequisites

- [Node.js](https://nodejs.org/en/download/)
- [npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm/)
- [TypeScript](https://www.typescriptlang.org/download/)
- [Viem](https://viem.sh)
- [Flare Wagmi Periphery Package](https://www.npmjs.com/package/@flarenetwork/flare-wagmi-periphery-package)

### Project setup

Create a directory and initialize npm:

```bash
mkdir fassets-settings-ftso
cd fassets-settings-ftso
npm init -y
```

Install the dependencies:

```bash
npm install --save-dev \
  typescript \
  viem \
  @flarenetwork/flare-wagmi-periphery-package
```

Create `tsconfig.json`:



### Script

```bash
mkdir scripts
touch scripts/fassets-settings.ts
```

Import viem and the `coston2` namespace from [`@flarenetwork/flare-wagmi-periphery-package`](https://www.npmjs.com/package/@flarenetwork/flare-wagmi-periphery-package):

```typescript
import { createPublicClient, http } from "viem";
import { flareTestnet } from "viem/chains";
import { coston2 } from "@flarenetwork/flare-wagmi-periphery-package";
```

```typescript
const FLARE_CONTRACT_REGISTRY_ADDRESS =
  "0xaD67FE66660Fb8dFE9d6b1b4240d8650e30F6019" as const;
const XRP_USD_FEED_ID = "0x015852502f55534400000000000000000000000000" as const;
```

```typescript
const client = createPublicClient({
  chain: flareTestnet,
  transport: http(),
});
```

Resolve `AssetManagerFXRP` from the [Flare Contract Registry](/network/guides/flare-contracts-registry):

```typescript
const assetManagerAddress = await client.readContract({
  address: FLARE_CONTRACT_REGISTRY_ADDRESS,
  abi: coston2.iFlareContractRegistryAbi,
  functionName: "getContractAddressByName",
  args: ["AssetManagerFXRP"],
});
```

Read [`getSettings`](/fassets/reference/IAssetManager#getsettings) and log the asset decimals:

```typescript
const settings = await client.readContract({
  address: assetManagerAddress,
  abi: coston2.iAssetManagerAbi,
  functionName: "getSettings",
});

console.log("Asset decimals:", settings.assetDecimals);
```

The same call returns the rest of the [operational parameters](/fassets/operational-parameters/#asset-manager-operational-parameters).

### Read the XRP/USD price

Read the XRP/USD [anchor feed](/ftso/scaling/anchor-feeds/) from [FTSO](/ftso/overview).

```typescript
const ftsoAddress = await client.readContract({
  address: FLARE_CONTRACT_REGISTRY_ADDRESS,
  abi: coston2.iFlareContractRegistryAbi,
  functionName: "getContractAddressByName",
  args: ["FtsoV2"],
});
```

`getFeedById` is `payable`, so use `simulateContract`:

```typescript
const {
  result: [_value, _decimals, _timestamp],
} = await client.simulateContract({
  address: ftsoAddress,
  abi: coston2.ftsoV2InterfaceAbi,
  functionName: "getFeedById",
  args: [XRP_USD_FEED_ID],
  value: 0n,
});
```

```typescript
const xrpUsdPrice = Number(_value) / Math.pow(10, Number(_decimals));

console.log("XRP/USD Price:", xrpUsdPrice);
console.log("Timestamp:", _timestamp.toString());
```

### Full script

```typescript title="scripts/fassets-settings.ts"
import { createPublicClient, http } from "viem";
import { flareTestnet } from "viem/chains";
import { coston2 } from "@flarenetwork/flare-wagmi-periphery-package";

const FLARE_CONTRACT_REGISTRY_ADDRESS =
  "0xaD67FE66660Fb8dFE9d6b1b4240d8650e30F6019" as const;
const XRP_USD_FEED_ID = "0x015852502f55534400000000000000000000000000" as const;

const client = createPublicClient({
  chain: flareTestnet,
  transport: http(),
});

const assetManagerAddress = await client.readContract({
  address: FLARE_CONTRACT_REGISTRY_ADDRESS,
  abi: coston2.iFlareContractRegistryAbi,
  functionName: "getContractAddressByName",
  args: ["AssetManagerFXRP"],
});

const settings = await client.readContract({
  address: assetManagerAddress,
  abi: coston2.iAssetManagerAbi,
  functionName: "getSettings",
});

console.log("Asset decimals:", settings.assetDecimals);

const ftsoAddress = await client.readContract({
  address: FLARE_CONTRACT_REGISTRY_ADDRESS,
  abi: coston2.iFlareContractRegistryAbi,
  functionName: "getContractAddressByName",
  args: ["FtsoV2"],
});

const {
  result: [_value, _decimals, _timestamp],
} = await client.simulateContract({
  address: ftsoAddress,
  abi: coston2.ftsoV2InterfaceAbi,
  functionName: "getFeedById",
  args: [XRP_USD_FEED_ID],
  value: 0n,
});

const xrpUsdPrice = Number(_value) / Math.pow(10, Number(_decimals));

console.log("XRP/USD Price:", xrpUsdPrice);
console.log("Timestamp:", _timestamp.toString());
```

```bash
npm run build
node dist/fassets-settings.js
```

## Solidity

Deploy a helper that reads FXRP asset decimals through `ContractRegistry`, then call it from Hardhat on Coston2.

### Prerequisites

- [Flare Hardhat Starter Kit](/network/guides/hardhat-foundry-starter-kit)
- [Flare Network Periphery Contracts](https://www.npmjs.com/package/@flarenetwork/flare-periphery-contracts)
- Node.js, TypeScript, and a Hardhat config with Coston2

### Contract

<CodeBlock language="solidity" title="contracts/FAssetsSettings.sol">
  {FAssetsAssetManagerSettings}
</CodeBlock>

{/* prettier-ignore */}
<RemixEmbed fileName="FAssetsAssetManagerSettings.sol">Open in Remix</RemixEmbed>

1. Import the [ContractRegistry library](/network/guides/flare-contracts-registry#contract-registry-library).
2. Import `IAssetManager` from [`@flarenetwork/flare-periphery-contracts`](https://www.npmjs.com/package/@flarenetwork/flare-periphery-contracts).
3. `FAssetsSettings` resolves the FXRP Asset Manager and calls [`getSettings`](/fassets/reference/IAssetManager#getsettings).
4. `getAssetDecimals` returns `assetDecimals`.
   The full settings list is on [FAssets Operational Parameters](/fassets/operational-parameters/#asset-manager-operational-parameters).

### Deploy and read

```typescript title="scripts/fassets/getAssetDecimals.ts"
// yarn hardhat run scripts/fassets/getAssetDecimals.ts --network coston2

const FAssetsSettings = artifacts.require("FAssetsSettings");

async function main() {
  const fAssetsSettings = await FAssetsSettings.new();
  console.log("FAssetsSettings deployed to:", fAssetsSettings.address);

  const assetDecimals = await fAssetsSettings.getAssetDecimals();
  console.log("Asset decimals:", assetDecimals.toString());
}

main().catch((error) => {
  console.error(error);
  process.exitCode = 1;
});
```

```bash
yarn hardhat run scripts/fassets/getAssetDecimals.ts --network coston2
```

```bash
Asset decimals: 6
```
