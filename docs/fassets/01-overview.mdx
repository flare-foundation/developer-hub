FAssets is a trustless, over-collateralized bridge connecting non-smart-contract networks to Flare.
It mints wrapped ERC-20 tokens (`FAssets`) that can be used in Flare DeFi or redeemed for the underlying asset.
FXRP, the representation of XRP, is the live FAsset.
The same model is designed for other non-smart-contract assets such as BTC and DOGE.

FAssets are powered by Flare's enshrined data protocols:

- **[Flare Time Series Oracle (FTSO)](/ftso/overview):** Provides decentralized price feeds.
- **[Flare Data Connector (FDC)](/fdc/overview):** Verifies offchain actions, such as transactions on other blockchains.

Each FAsset is backed by two kinds of collateral:

1. **Vault collateral:** a governance-approved stablecoin locked by the agent.
   For FXRP on Flare, that token is USDT.
2. **Pool collateral:** FLR on Flare, or SGB on Songbird, supplied by the agent and by collateral providers.

Agents and a community-provided collateral pool keep the system over-collateralized.

Anyone can mint FAssets on Flare.
An FAsset is the ERC-20 form of an underlying asset from a non-smart-contract network.
Today that underlying is XRP on the XRP Ledger, and the minted token is FXRP.

### Minting

Public minting for XRP is one payment to the [Core Vault](/fassets/core-vault):

- The minter sends XRP on the XRP Ledger to the Core Vault address.
  A destination tag or memo names the Flare recipient and, optionally, an executor.
- The [FDC](/fdc/overview) verifies the payment.
- An executor calls `executeDirectMinting` on the AssetManager.
  FXRP is minted to the recipient.

Fees come out of the XRP payment.
See [Minting](/fassets/minting) for tags, memos, fees, and rate limits.

The collateral-reservation flow (select an agent, reserve collateral, pay that agent) is archived in [Standard Minting](/fassets/standard-minting).

### Usage

Minted FAssets can be used in DeFi applications on Flare or bridged to other chains.

### Redeeming

Users can redeem FAssets for the original underlying assets at any time.

## Key Participants

### Agents

Agents manage the infrastructure and operations of the FAssets system, including:

- Holding the underlying assets.
- Providing collateral for minting and redemption.
- Redeeming underlying assets for users.

Each agent is verified through governance and uses the following addresses on the native chain:

- **Work Address:** A hot wallet for executing operations.
- **Management Address:** A cold wallet for secure administrative actions.

Agents must comply with the **backing factor**, which ensures sufficient collateral is locked to back FAssets.

Agents can also mint FAssets from their own vaults.
This is **self-minting**, an agent path.
Public FXRP minting uses the Core Vault payment above.
When an agent self-mints:

- The agent pays the amount to mint on the underlying chain and executes the minting.
- The self-minting operation adds a [ticket to the redemption queue](/fassets/redemption#redemption-tickets-and-the-redemption-queue), alongside tickets from other users.
- Agents can create vaults that are not public, so the vault can only be used to self-mint.

### Users

Users interact with the system by:

- **Minting:** Depositing underlying assets to mint FAssets.
- **Redeeming:** Exchanging FAssets for the original underlying assets.

Eligibility:

- No restrictions—anyone can mint or redeem FAssets.

### Collateral Providers

Collateral providers supply native FLR tokens to an agent's collateral pool and earn a share of minting fees as long as their tokens remain locked.

### Liquidators

Liquidators maintain system health by:

- Burning FAssets in exchange for collateral when an agent's collateral drops below the required minimum.
- Earning rewards, including premiums on the collateral received.

Eligibility:

- Open to all—anyone can become a liquidator.

### Challengers

Challengers monitor agents for illegal transactions that reduce collateral below the backing factor.
They:

- Submit proof of illegal actions to the system.
- Earn rewards from the agent's vault upon successful challenges.

If an agent is found in violation, they enter **full liquidation**, permanently restricting them from new minting operations.

## Core Vault

The [Core Vault](/fassets/core-vault) is a per-asset multisig on the underlying network.
Public FXRP minting pays XRP into that vault.
Agents can also deposit underlying there, which frees the collateral that was backing those assets.
No single agent owns the vault, and governance can pause it.
