FAssets run on Songbird and on Coston, as well as on Flare Mainnet and Coston2.

Build applications against **Coston2** (chain ID `114`) and deploy them on **Flare Mainnet** (chain ID `14`).
Songbird (chain ID `19`) is the canary network for live protocol experiments.
Coston (chain ID `16`) is the protocol testnet for Songbird.
The same setting can differ on each network.
Read the live values on [Operational Parameters](/fassets/operational-parameters).

FXRP is the FAsset for XRP on these networks.
Public minting is one XRP Ledger payment to the [Core Vault](/fassets/core-vault), then an executor calls `executeDirectMinting` on Flare.
See [Minting](/fassets/minting).

The earlier Songbird open-beta terms, including the issuance cap, the loss underwrite, and the fixed test window, applied only to the trial before FAssets shipped on Flare Mainnet.
