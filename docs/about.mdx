Flare Developer Hub ([dev.flare.network](https://dev.flare.network)) is the official documentation site for developers building on **Flare**, an EVM-compatible Layer 1 blockchain designed for data-intensive and interoperable applications.

Flare’s key differentiator is **enshrined data**: core data protocols are built into the network rather than bolted on as third-party infrastructure.
Those protocols include:

- **[FTSO (Flare Time Series Oracle)](/ftso/overview)** — decentralized price and time-series feeds, with FTSOv2 as the current developer interface.
- **[FDC (Flare Data Connector)](/fdc/overview)** — attestations that let contracts verify data from external chains.
- **[FAssets](/fassets/overview)** — trust-minimized representations of assets such as XRP and BTC for use in Flare DeFi.
- **[Smart Accounts](/smart-accounts/overview)** — account abstraction that helps XRPL users interact with Flare applications.
- **[FCC (Flare Confidential Compute)](/fcc/overview)** — Trusted Execution Environments (TEEs) for secure offchain computation, cross-chain transaction signing, and fast data attestation.

This site publishes tutorials, Solidity and SDK references, network configuration (Mainnet, Coston2, Songbird, Coston), OpenAPI specifications, Markdown mirrors for AI agents, `llms.txt`, and a first-party MCP server at `/mcp`.

The Developer Hub is maintained by the Flare open-source community under the [flare-foundation/developer-hub](https://github.com/flare-foundation/developer-hub) repository.
Product and ecosystem information for Flare more broadly is available at [flare.network](https://flare.network/).
