Flare places the highest priority on the security and reliability of its network and protocols.
To ensure integrity, independent, reputable security firms conduct thorough audits of node software, smart contracts, and critical offchain components.

Below is a list of completed audits, grouped by protocol or component.
Each report provides detailed insights into the scope of the audit, methodologies used, findings, and remediation status where applicable.
